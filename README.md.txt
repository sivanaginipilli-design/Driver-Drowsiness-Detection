 Driver Drowsiness Detection System

A Real-Time Driver Drowsiness Detection System built using Python, OpenCV, and Dlib. It monitors eye movements (Eye Aspect Ratio - EAR) through a webcam and triggers an audio alarm when prolonged eye closure or fatigue is detected.
 🚀 Features
- Real-time webcam monitoring.
- Facial landmark detection using Dlib.
- Eye Aspect Ratio (EAR) calculation to detect drowsiness.
- Audio alert system using Pygame.

 📁 Prerequisites & Downloads
1. Install Python 3.x on your system.
2. Download the **Facial Landmark Predictor Data**:
